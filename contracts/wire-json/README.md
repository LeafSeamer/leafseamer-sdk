# 受限原始 JSON 解码参考

`wire-json/0.1.0-draft.1` 将 DF01 第 8 节的原始报文设计变成可执行参考。当前 `approved=false`、`runtime_ready=false`；不改旧契约、服务入口或既有选择摘要，也不自动启用更严格的接受集。

本包使用固定 [Suite 设计与向量](https://github.com/LeafSeamer/leafseamer-suite/tree/794285ab03373dee253981f2dfec897d7ddbb655/docs/contracts/df01)。两份来源原件位于 [source](source/decoder-design-cases.json)，输入摘要和上游提交见 [sources.json](sources.json)，沿用项目 [Apache-2.0 许可](../../LICENSE)。新完整模型图作为实际引用验证输入，不能因此宣称全部领域语义都已迁入。

## 处理顺序

[wire.py](wire.py)只接受不可变 `bytes` 和可信代码先行安装的 `Schema`／`Profile`：长度、期限与取消 → 拒绝 BOM → 严格 UTF-8 → 显式容器栈审计 → 同一文本构值 → 原始数字感知的 Schema 检查 → 深度只读 DTO。任何步骤失败均不返回可受理 DTO。

扫描器检查完整 JSON 文法、单根、解码后的重复键、Unicode scalar 与非字符、对象成员数、值节点数、深度、键／字符串解码字节、数字词法长度及指数。键不规范化，`__proto__` 保持数据；错误仅有固定阶段、代码和可选字节偏移，不返回原文或动态属性路径。

数字 token 保留本次私有的 JSON Pointer 和原始半开字节区间。消去系数尾零后判定数学整数与安全范围，不根据攻击者指数构造大幂。所有数字要求有限 binary64；非零数学值下溢为零拒绝。`integer` 额外要求原始数学整数且绝对值不超过 9007199254740991；`number` 保留 binary64 近似语义。因此 `1.0`／`1e0`可通过整数类型，`1.0000000000000001`不能先舍入再通过。

Schema 使用私有校验类的整数类型判定，保留原 `if/then/else`、`allOf/anyOf/oneOf`、nullable 与引用分支。私有副本中的方言标识同步改绑，防止嵌套 `$schema` 或引用切回普通整数判定；公开原件不改。只遍历正式 Schema 位置，`const`／`examples`中的业务数据不当成类型声明；完整图的整数节点路径逐项验证。外部引用禁用，未解析引用失败关闭，不运行网络获取。

## 预算与执行边界

默认使用固定实验 profile：65536 字节、容器深度32、16384值节点、每对象4096成员、单键1024解码字节、单字符串32768解码字节、数字128字符、指数绝对值4096。预算等号允许、超一拒绝；全部配置有限且不能用零或布尔值关闭。期限100ms使用本地单调时钟，从入口开始到只读结果返回均须成立；扫描每4096计步检查取消和期限，时钟倒退拒绝。

这是**同步 Python 参考**。检查点不让出线程，平台构值、Schema正则和校验只能在调用返回后观察超时，不提供硬抢占或保护通路时延保证。生产仍须实现受限 worker 池、传输重组限额、Schema批准／编译资源限制、真实内存与最坏耗时验收。Schema 安装只用于可信本地来源，不能暴露为客户端上传编译接口。

输出 DTO 用只读映射、元组和标量表示；token仅用于内部测试与审计，不得直接送日志或公共响应。深度只读不构成模块隔离。本包不实现关联语义、动态能力授权、JCS、HTTP媒体类型、WS重组、持久消费或设备命令；非法响应不能被解释成原写入未受理，也不能据此重发。

## 验证

在 SDK 根目录使用已安装 `jsonschema==4.25.1`、`referencing` 的 Python 环境及 Node：

```text
python -I -B contracts/wire-json/check.py
python -I -B contracts/wire-json/check.py --check-report
```

[检查器](check.py)实际执行原30条报文向量、预算等号／超一、非法字符、数字条件分支、错误脱敏、并发上下文和完整图整数节点映射。固定种子的200条语法／值差分与平台解析器对照；[独立 Node 算术](number-oracle.mjs)以 BigInt 和 V8 比对22条数字的整数性质、安全范围及 binary64 位模式。它不是完整 JS 扫描器或浏览器验收，实际工具版本见 [报告](report.json)。

`--check-report`只核对报告绑定，不执行行为用例。默认候选未接到任何服务；将来启用必须明确协议版本、可信操作／预算绑定及跨语言接受集差异，不能悄悄收紧旧选择。阶段0和项目总体仍未完成。
