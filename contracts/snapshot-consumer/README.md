# 固定快照消费与原子投影替换

本候选接续 [订阅交付接线](../channel-release/README.md)，实现完整快照的隔离下载、校验、SQLite 投影替换及 `client.snapshot.applied` 生成。保持既有 Manifest、PageResponse 和 SnapshotApplied 原件不变，`approved=false`、`runtime_ready=false`。

## 可信输入与页面边界

[Consumer](consumer.py) 的 `start()` 接收认证附着结果与批准 Profile 提供的精确 ContentBinding、DeliveryBinding、SnapshotRef、集合 SchemaRef 和单调截止时刻。不能从下载清单重新计算这些值后视为批准；此参考不实现认证提供者。连接代次与内容身份分开，旧连接的同内容页仍拒绝。

Manifest 必须与附着结果固定的快照 ID、游标和摘要完全一致，集合及 SchemaRef 与批准清单相同，显式保留空集合。页描述符必须恰好覆盖连续页号，总字节数相符。页面可乱序下载；相同规范正文的重复页幂等。每页重新验证绑定、下一页位置、完整规范内容字节数及摘要。末页标记不能代替完整页集合。

原始 JSON 先走固定 SDK 严格解码器，再检查当前 Schema。JCS 摘要比较区分布尔与数值，不依赖 Python 宽松对象相等。游标和修订使用原十进制字符串。清单 UTC 时间只验证元数据先后；实际资格和期限来自可信单调时钟，不能用本机壁钟自动续期。

完整应用时再次核对全部页、跨页对象排序与唯一性、集合计数，以及来源记录与完整 watermark 的一一对应。此检查证明收到了清单声明的全部内容，不独立证明发布者未遗漏权威数据库中的对象。十二类 Record 的结构沿固定 SDK 图；其真实来源、动态 Schema 批准及各领域完整语义仍由相应提供者和领域验收负责。

## 六表与原子提交

[SQLite 布局](projection.sql) 保存构建代、slot 当前构建代、暂存页、具名投影记录、应用确认及活动投影指针。一个 slot 表示宿主批准的独立显示位置；它不是远端可自由选择的账号或权限键。

开始新快照立即隐藏本消费者的旧投影。成功登记新构建代后，同 slot 的其他旧消费者也因数据库中的代际检查失效。下载或校验失败不能回退展示旧权限数据；其他 slot 不受影响。数据库打开或创建新 Consumer 均不会自动恢复授权或可见投影。读取投影在同一短读事务中核对代际、活动指针和记录，返回前结束事务；已经返回给调用者的副本无法撤回，实际 UI 清理及网络释放仍需单独接线。

`apply()` 在一个新 writer 事务内校验完整包、插入全部记录、插入精确应用确认、替换活动指针，并在提交前再次检查当前资格和期限。任何一步失败都回滚到完整原状态。另一 SQLite 读取连接在提交前只能看到旧投影，提交后才能看到完整新投影。空快照也通过同一事务替换，不能在收到部分页时提前删除对象。

提交完成后才返回应用确认。如果提交成功但结果观察丢失，不返回成功；同一仍有效构建代可按原提交身份查原，返回原确认且不重放记录。新代建立或资格失效后，旧代即使有历史确认也不能重新返回它作为当前成功。数据库写调用只允许建立 Consumer 的线程；其他线程可以同步 `invalidate()`，关闭投影可见性。

SQL 外键把活动指针约束到已有确认；完整页集合、摘要和计数由应用层验证。此布局不是完整生产 DDL，也不防御拥有任意数据库写权限的本机程序。数据库连接使用 WAL 和 FULL 同步，测试中的事务回滚与双连接观察不等于掉电耐久证明。

## 容量与剩余交付

当前候选限额为：清单 64 KiB、完整页面响应 256 KiB、页内容 240 KiB、128 页、整包 8 MiB、32768 条记录、数据库内64个构建代及32 MiB暂存页正文。超限直接拒绝；这些是参考限额，不是批准的生产容量。历史 GC、空间回收及迁移尚待统一，不自动删除历史换取表面成功。

检查器使用 Controller／Seamer 两组覆盖全部十二类 Record，运行实际 SQLite 文件、跨连接观察、同 slot 替换、独立 slot 保留、乱序／重复／漏页、跨代混页、重封摘要后的语义变异、逐写入故障及提交观察丢失。还把实际生成的确认交给原订阅模型，再通过既有释放门交付首个补齐帧，验证快照游标成为交付链前驱。

```text
python -I -B contracts/snapshot-consumer/check.py
python -I -B contracts/snapshot-consumer/check.py --report
python -I -B contracts/snapshot-consumer/check.py --check-report
```

[报告](report.json) 绑定全部输入；最后一个命令只核验摘要，不重新执行行为检查。生成应用确认不证明确认已通过网络发送；发送前仍需当前连接及出口资格。增量应用、修订墓碑、规范来源 inbox／触发事务、浏览器持久化、页面渲染及真实网络均未实现或验收，本包不生成 `durable_ingest` ACK，也不自动将运行状态恢复为 armed。阶段 0 仍未关闭。
